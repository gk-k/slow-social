🗺️ Slow Social — App Map & Architecture Guide

This document serves as your take-home reference map for the Slow Social proof of concept.

1. System Architecture Overview

A minimalist, non-instant social web application built with Vue 3 (Vite), Tailwind CSS, and Firebase (Firestore + Anonymous Auth).

2. Guided Code Route (Key Locations)

1. Entry Point & State Orchestration src/App.vue

Initializes Firebase Anonymous Auth and listens to the Firestore posts collection in real-time using onSnapshot. Manages the virtual time offset and language state.

2. Language & Dictionary Dictionary src/messages.js

Stores English and Japanese translation keys for all UI text, allowing instant 1-click language switching.

3. Text Submission src/components/PostComposer.vue

Captures user input and calculates a random delay between 2 to 5 minutes before calling Firestore's addDoc.

4. Time Filtering & Card Rendering src/components/PostCard.vue

Compares createdAt + delayMinutes against virtualNow. Handles the 1-reaction limit per browser via localStorage.

5. Reactions Summary Modal src/components/ReactionModal.vue

Renders a clean popup tallying the preset reactions (Like, I feel you, Same here, Great job) received for the author's published post.

3. To Change This, Start Here

  • Add or Modify Languages: Edit src/messages.js.
  • Change Delay Time Range: Modify randomDelayMinutes calculation in src/App.vue.
  • Add New Preset Reactions: Update reactionKeys in src/messages.js and the Firestore default map in src/App.vue.

4. A Practice to Reuse

Client-Side Simulation for Rapid PoCs:
Instead of building complex server-side scheduled triggers (Cloud Functions) for the non-instant delay, calculating state on the client side using timestamps saved hours of setup while perfectly validating the user experience.

5. How to Run Locally

cd slow-social npm install npm run dev # Open http://localhost:5173
