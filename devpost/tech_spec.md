# Slow Social App — Technical Spec

## How This Works, In Plain Language
The app is a single-page frontend built with Vue.js. It connects directly to a Firebase backend. When a user opens the app, Firebase silently assigns them an anonymous ID (so they don't have to log in). When they write a post, the app saves it to a Firestore database with a timestamp. The app constantly watches the database: if a post is less than a few minutes old, only the author sees it (as "pending"). Once the time passes, it shows up for everyone. When someone clicks a reaction button, the app simply increments a counter on that specific post in the database.

## The Core Journey Through the System
1. **Arrival:** User loads the Vue.js app. Firebase Anonymous Auth initializes and provides a unique `uid`.
2. **Post Creation:** User types text and clicks post. The Vue component calls Firestore `addDoc` to save the message, author `uid`, and current `timestamp`.
3. **Queueing (Client-Side Logic):** The app fetches posts from Firestore. It compares the post's `timestamp` to the current time. If `current time - timestamp < random_delay`, it is shown only in the "My Posts" column (Pending).
4. **Publishing:** Once the delay condition is met, the post automatically appears in the "Public Posts" column for all users.
5. **Reacting:** Another user clicks "👍 いいね！". The Vue app calls Firestore `updateDoc` (or `increment`) to update the reaction count for that post document.
6. **Viewing Reactions:** The author clicks their post. A Vue modal component opens, reading the reaction counts from that local post object.
PRD ref: `prd.md > The Core Journey`.

## Stack
- **Frontend Framework:** Vue.js (via Vite)
  - *Rationale:* Chosen by the learner based on professional preference and comfort. Excellent for reactive UI and component separation. [Vue.js Docs](https://vuejs.org/)
- **Styling:** Tailwind CSS
  - *Rationale:* Rapid, utility-first styling to easily achieve the "ocean/calm" aesthetic without writing large custom CSS files. [Tailwind Docs](https://tailwindcss.com/)
- **Backend / Database:** Firebase (Firestore & Anonymous Auth)
  - *Rationale:* Essential for cross-user interaction (seeing others' posts) without building a custom backend. Anonymous Auth handles identity frictionlessly. [Firebase Docs](https://firebase.google.com/docs)
- **Hosting (Later/Optional):** Firebase Hosting
  - *Rationale:* Easiest path to deploy a Vue + Firebase app if a live URL is desired.

## Where It Runs and How Someone Tries It
- **Development:** Runs locally using Node.js (`npm run dev`).
- **Demo Recording:** The learner will run the dev server locally, open it in a browser, and open a second browser window (incognito) to simulate two users interacting.
- **Environment Requirements:** Node.js installed, Firebase project created with Firestore and Anonymous Auth enabled, and a `.env` file containing Firebase config keys.

## Data Model
**Firestore Collection:** `posts`
- `id` (String, auto-generated by Firestore)
- `authorId` (String, from Firebase Anonymous Auth)
- `content` (String)
- `createdAt` (Timestamp)
- `delayMinutes` (Number, randomly generated between 2-5 at creation)
- `reactions` (Map/Object):
  - `like` (Number, default 0) // 👍 いいね！
  - `understand` (Number, default 0) // 🤝 わかる〜
  - `sameHere` (Number, default 0) // 🌊 うちもおなじ
  - `cheers` (Number, default 0) // 🍵 お疲れ様

*Note on Security:* For this PoC, standard test-mode Firestore rules (open read/write) or simple auth-required rules will be used.

## External Services and Dependencies
- **Firebase Firestore:** Used to store posts and reactions.

## Important Failure Modes
- **Firebase not connected / Offline:** The app will fail to fetch posts. *Fallback:* Show a calm error message in the feed area ("静かな海で通信が途絶えています。少し待ってリロードしてください。").
- **Empty Feed:** No posts exist yet. *Fallback:* "My Posts" shows "最初の投稿をしてみましょう", "Public Posts" shows "まだ誰も投稿していません。波の音を聴いて待ちましょう。"

## What Was Simplified and Why
- **Delay Logic:** Instead of a complex server-side cron job or Cloud Function to "publish" posts, the delay is calculated *client-side*. The Vue app fetches all posts, but hides or marks posts as "pending" if `now < createdAt + delayMinutes`. This completely removes backend complexity while achieving the exact same user experience for the PoC.
- **Anonymous Auth:** Avoids building login screens and managing passwords, which would bloat the 2-4 hour PoC scope.
- **Demo Recording Aid:** Added a debug button in `App.vue` to artificially fast-forward the client's concept of time, allowing for a smooth 1-minute demo recording without actually waiting 5 minutes.
